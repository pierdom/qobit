# qobit logo pack

Colours (Ayu Dark): q #E6B450 · sample wave #59C2FF · tile #0B0E14 · wordmark text #BFBDB6 (dark) / #0B0E14 (light)

- qobit-mark.svg: 96×96 app icon on the dark tile (drop-in replacement for docs/assets/qobit-mark.svg)
- qobit-glyph.svg: the q alone, transparent background
- qobit-wordmark-dark.svg / -light.svg: q + "obit", for dark / light backgrounds
- favicon.svg + png/: rasterised icon at 16, 32, 180, 512, 1024 px; glyph at 512 px

The wordmark sets "obit" in Inter 500 as live text. Viewers without Inter (including GitHub's image renderer) fall back to a system sans; convert the text to outlines in Inkscape/Figma for a fully font-independent file.
